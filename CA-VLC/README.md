# CA-VLC

Official implementation of CA-VLC: Confidence-Aware Semi-Supervised Vision–Language Contrastive Learning for Abnormal Behavior Recognition.

## Introduction

CA-VLC is a confidence-aware semi-supervised vision–language contrastive learning framework for abnormal behavior recognition with limited labeled data. It integrates confidence-aware pseudo-label selection, stop-gradient supervision, cross-view consistency learning, and contextual semantic alignment to exploit unlabeled videos while reducing the influence of unreliable pseudo-labels.

Experiments on CABR50 under different labeled-data proportions, together with transfer evaluations on CABRZ6 and UCF-101, demonstrate the effectiveness and generalizability of the proposed framework.

The source code, trained models, configuration files, and related data will be made publicly available upon publication of the paper.
