# NSP-ML

Official implementation of **NSP-ML: Normality-Guided and Spatiotemporal Prior-Aware Multimodal Learning for Abnormal Behavior Recognition** 
## Introduction

NSP-ML is a context-sensitive abnormal behavior recognition framework that incorporates normality-guided logs and spatiotemporal prior-aware knowledge to construct context-conditioned behavioral hypotheses and align them with visual evidence.

The source code, trained models, and related data will be made publicly available upon publication of the paper.
